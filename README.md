## How I work with AI

I wrote code the classic way for almost all my career, before AI tools existed.
In recent years I have started using AI more and more, and today I use
Claude and Claude Code every day. My coding experience is what lets me
use AI well: I know what good code looks like, and I can see when a
suggestion is wrong.

My rule is simple: the AI never makes a design decision without me.

- I start by analyzing the problem with Claude. It presents the options
  and the trade-offs, and I choose.
- When the design is clear, Claude helps me write a detailed prompt for
  Claude Code with all the decisions in it.
- In Claude Code I follow the same approach. It explains what it is about
  to do before it writes code, and I review each change and each commit.

This way I keep track of every change, and I can explain and defend
every choice in the code.
